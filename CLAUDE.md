# VideoEditor

Панель массовой заливки видео на YouTube для байеров. Python HTTPServer + YouTube API,
мультипользователи, квоты, OAuth через Octo Browser, интеграция с Binom.

**Крео и связки — тоже здесь.** Это один конвейер: оффер у аффа → крео → ленд → залив.
